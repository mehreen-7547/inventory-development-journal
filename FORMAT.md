# How this journal is written

- One folder per module, one file per chapter, one section per step.
- Steps are numbered from Step 1 (the first step of the whole project). Numbers never change.
- A step is one instruction that changes something: a file is created or edited, or a command changes the project.
- Each step shows the files in the order they were opened and only the lines added or changed.
- Checks and tests are written under the step they test ("How we checked it").
- One Git commit per step. Commit message: `Step N: title`.
